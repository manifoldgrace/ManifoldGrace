# Manifold Grace learning projects

39 separate starter workspaces for Grace R. Nettey's research and manual tinkering: 20 company investigations, ten MA-connected avenues and nine bottleneck investigations. Created 5 November 2026. Existing repository files are preserved.

Each folder has a focused fictional pilot, source-code links at a checked revision, scope/licence notes, an editable hand-annotation notebook and an offline Python starting point. These are research setups, not completed features, validated findings or vendor endorsements. No upstream code has been imported; some linked code is an SDK, some an evaluation tool, and three research repositories have no top-level licence identified. Service access, model weights and datasets may have separate terms or costs.

The website remains the canonical home for research descriptions; this collection provides working files. Related projects may share an upstream toolkit while retaining different questions, cases and notes. Source accessibility was checked on 5 November 2026; source code and licence links are distinct from product documentation. Source versions can change after that date.

## Use and attribution

Clone this repository, open a folder and run its `experiment.py` to inspect the plan offline. Record and annotate observations before drawing conclusions. Nothing installs packages or calls an API automatically. Follow the folder README when you later select an actual experiment or inspect upstream code.

Grace supplied the research direction and requested these workspaces; AI assistance prepared the scaffolds, link register and initial fictional pilots. These are not claims that Grace authored the upstream projects. Preserve upstream licences/notices when incorporating permitted code. Do not infer permission to redistribute a public repository with no licence.
